ТЕКШЕР МЗКМ — WEB

ВАЖНО:
- API не используется.
- Backend не используется.
- КМ не отправляются на сервер.
- КМ хранятся локально в браузере.
- CSV содержит только КМ, по одному на строку.
- Заголовков и дополнительных полей нет.
- GS / ASCII 29 (U+001D) сохраняется в экспортируемом значении.
- В интерфейсе GS показывается как ␝ только для удобства просмотра.

Зависимости подключены через CDN:
- React 18
- ReactDOM 18
- html5-qrcode 2.3.8

Для промышленной публикации рекомендуется затем зафиксировать JS-библиотеки локально, чтобы приложение не зависело от CDN.
